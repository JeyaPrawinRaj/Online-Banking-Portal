# 💳 Online Banking Portal

## 📌 Project Overview
The Online Banking Portal is a web-based application designed to provide secure and convenient banking services to users. 
It eliminates long queues and manual banking processes by offering digital access to banking operations.

## 🚀 Features
- User Registration & Login
- Check Account Balance
- View Transaction History
- Bill Payments
- Admin Dashboard for Account Management
- Secure Authentication System

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java / Node.js
- Database: MySQL

## 🔐 Security Features
- User authentication
- Secure data handling
- Role-based access (User/Admin)
